# vetport

Vet filesystem port paths across POSIX and Windows conventions.

**Site:** https://theworker02.github.io/vetport/

## Install / run

```bash
git clone https://github.com/theworker02/vetport.git
cd vetport
node src/cli.js
node --test
```
